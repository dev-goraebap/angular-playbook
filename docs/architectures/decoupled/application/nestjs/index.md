# NestJS 아키텍처

본 문서는 NestJS 기반 백엔드 애플리케이션의 구조와 설계 결정을 기술할 자리입니다. **아직 작성되지 않았습니다.**

## 작성 예정 범위

[Angular 표준](../angular/index.md)과 같은 구성을 따릅니다. 개요에 품질 목표와 제약 조건, 전략을 두고 세부 규칙은 참조 문서로, 선택의 사유는 결정 기록으로 나눕니다.

프론트엔드 표준과 맞물리는 항목이 둘 있습니다. **API 계약**은 [API 계약 소비](../angular/concepts/API-계약-소비.md)가 프론트엔드 쪽 규칙을 이미 정의하고 있으므로, 백엔드 표준은 그 반대편인 계약 발행과 변경 절차를 담습니다. **인증**은 [보안](../angular/concepts/보안.md)이 토큰 보관을 프론트엔드 책임으로, 인가 판정을 서버 책임으로 나눠 두었습니다.
