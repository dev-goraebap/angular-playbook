# Spring Boot 아키텍처

본 문서는 Spring Boot 기반 백엔드 애플리케이션의 구조와 설계 결정을 기술할 자리입니다. **아직 작성되지 않았습니다.**

## 작성 예정 범위

[Angular 표준](../angular/index.md)과 같은 구성을 따릅니다. 개요에 품질 목표와 제약 조건, 전략을 두고 세부 규칙은 참조 문서로, 선택의 사유는 결정 기록으로 나눕니다.

[NestJS 표준](../nestjs/index.md)과 같은 범위를 다루되 결론은 각자 정합니다. 두 스택이 같은 문제를 다르게 푸는 지점은 그 자체로 기록할 가치가 있으므로, 한쪽을 다른 쪽에 맞추지 않습니다.
