# Spring Boot 아키텍처

본 문서는 Spring Boot 기반 백엔드 애플리케이션의 구조와 설계 결정을 기술할 자리입니다. **아직 작성되지 않았습니다.**

## 작성 예정 범위

[Angular 아키텍처](../angular/index.md)와 같은 구성을 따릅니다. 개요에는 **원본을 가진 절만** 두고, 세부 규칙은 횡단 개념으로, 선택의 사유는 결정 기록으로 나눕니다.

품질 목표의 서열은 Angular 문서를 그대로 따르지 않습니다. 프론트엔드의 1순위가 예측 가능성인 것은 주 독자가 에이전트라 배치가 결정적이어야 하기 때문이며, 백엔드는 다른 서열을 가질 수 있습니다. **서열을 먼저 정하고 나머지 결정을 그것으로 설명합니다.**

[애플리케이션 아키텍처](../index.md) 5절이 "경계에 걸친 결정"의 원본을 아직 Angular 문서로 두고 있습니다. 본 문서를 채우는 시점에 그 여섯 항목을 상위로 올리고, 양쪽 스택 문서에는 그것을 소비하는 규칙만 남깁니다.
